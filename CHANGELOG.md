# Changelog

## 1.0.0 — 2026-10-18

### Added

- `.hsj` container/protobuf parser, v1 LZ4 / v2 Zstd layer decoder.
- Layer tree, group flattening, clipping masks, background layer and blend modes.
- PSD writer (PackBits RLE, layer names, visibility, opacity, clipping, lock alpha,
  resolution info, merged preview).
- ORA writer (nested stacks, clipping bake, PNG layers, merged image).
- CLI: PSD / ORA / both, `--list`, `--no-bg`, `--force`.
- Modern dark Windows tkinter GUI with layer tree, progress, logs, shortcuts and
  custom dialogs.
- Multi-size application icons and installer artwork generated by scripts.
- PyInstaller packaging for GUI, CLI and portable zip.
- NSIS Chinese installer with optional `.hsj` association.
- Native Android app (Kotlin + Jetpack Compose): SAF import/output, layer tree,
  PSD/ORA/both, background and overwrite options, foreground service progress
  and cancellation, logs, open/share, adaptive icon.
- Streaming Android core with mapped surfaces for 6000×6000 drafts.
- JVM parity tests and device instrumentation tests against Python references.

### Fixed

- Android release builds must keep `net.jpountz.lz4.**` for reflective
  `LZ4Factory` loading under R8.
- Windows non-ASCII project paths: ASCII build junction and ASCII core build
  directory for JVM tests.
